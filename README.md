# tmkeesey.net

Personal résumé website for T. Michael Keesey.

Built with [Next.js](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/).

## Development

```bash
yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
yarn build
yarn start
```

## Content

Résumé content lives in `src/data/cv.json`. Edit that file to update the page.

Replace `public/images/portrait.svg` with your photo at `public/images/portrait.jpg` (146×162 px recommended) and update `Header.tsx` accordingly.

## Deploy

This is a standard Next.js app and can be deployed to [Vercel](https://vercel.com/) or any platform that supports Next.js.
